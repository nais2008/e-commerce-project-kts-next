# e-commerce-project-kts-next

Интернет-магазин c мобильной адаптацией с функционалом корзины,
просмотра, покупкой и фильтрацией товаров. Есть авторизация,
регистрация и просмотр профиля. Через страницу категорий можно выбрать
фильтр для товаров.

## Клонирование репозитория

```cmd
git clone https://github.com/nais2008/e-commerce-project-kts-next
cd ./e-commerce-project-kts-next
```

## Заполнение переменных среды

### Создание файла

```cmd
touch .env
```

### Заполняем

```env
VITE_NEXT_PUBLIC_STRAPI_TOKEN=your_strapi_token
```

## Установка зависимостей

```cmd
npm install
```

## Запуск

```cmd
npm run dev
```
